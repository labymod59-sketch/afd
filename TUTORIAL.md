# Как собрать Ember через GitHub

## 1. Создайте репозиторий

1. На github.com нажмите **New repository**, назовите `Ember`, сделайте его **публичным**
   (на бесплатном тарифе минуты Actions безлимитны только для публичных репозиториев; GPL всё равно требует открытый код).
2. Загрузите в корень репозитория всё содержимое этой папки:
   `.github/`, `ember-overlay/`, `tools/`, `LICENSE`, `README.md`, `TUTORIAL.md`.
   Проще всего: `git init`, `git add .`, `git commit`, `git remote add origin ...`, `git push`.
   Через сайт папку `.github` и скрытый файл `ember-overlay/.deleted` загружать неудобно, используйте git.

## 2. Свои ключи Telegram (рекомендуется)

1. Зайдите на https://my.telegram.org/apps и создайте приложение. Получите `api_id` и `api_hash`.
2. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**.
   Создайте два секрета: `EMBER_API_ID` и `EMBER_API_HASH`.

Без них используются тестовые ключи из документации. Для себя это сработает, но лучше свои.
Ключи не публикуйте в коде.

## 3. Запустите сборку

1. Вкладка **Actions** → **Build Ember** → **Run workflow**.
2. Версию оставьте `7.2.9` (оверлей сделан именно под неё). Выберите Linux и/или Windows.
3. Ждите. Linux: примерно 1–2 часа. Windows: 3–5 часов, первая сборка библиотек самая долгая.

Если Windows-сборка упала по таймеру или на сбое сети, просто запустите снова. Собранные библиотеки
кэшируются и продолжатся с того места, где остановились.

## 4. Скачайте результат

Откройте завершённый запуск, внизу блок **Artifacts**: `Ember-windows-x64` (там `Ember.exe`) и
`Ember-linux-x64` (`.tar.gz`). Для автоматического релиза создайте тег: `git tag v1.0 && git push --tags`.

## 5. Первый запуск

Приложение стартует с чёрной темой. Войдите в аккаунт. Данные хранятся отдельно от Telegram и AyuGram.

## Ember-подарок: как проверить

1. Откройте свой профиль, нажмите **Ember-подарок**, выберите подарок и **Применить**.
2. С другого аккаунта в Ember откройте ваш профиль: должна появиться кнопка **Ember-подарок**.

Как это работает: выбор записывается в конец вашего био невидимыми символами (16 штук).
Ограничения: лимит био 70 символов (140 с Premium); сервер Telegram теоретически может вырезать такие символы.
Тогда подарок не отобразится, и нужен собственный сервер для хранения.

## Если сборка упала

Откройте красный шаг в логе и скопируйте последние ~50 строк ошибки. Типичные причины:

- **«No tag for AyuGram Desktop ...»**: версия указана неверно.
- **Ошибка компиляции в `ember_gifts.cpp`**: код писался без возможности его скомпилировать, нужна небольшая правка.
- **Нехватка места на диске (Windows)**: перезапустите, а если повторится, нужен self-hosted раннер.

## Как менять дальше

- Цвета: `tools/make_theme.py` (акцент, поверхности), результат кладётся в `ember-overlay/Telegram/Resources/night.tdesktop-theme`.
- Иконка: `tools/make_icons.py`.
- Код подарков: `ember-overlay/Telegram/SourceFiles/ember/`.

Когда выйдет новая версия AyuGram, оверлей придётся обновить: перенесите изменения на новые файлы.
