# Ember

Чёрный неофициальный клиент Telegram на базе [AyuGram Desktop](https://github.com/AyuGram/AyuGramDesktop)
(который сам основан на [Telegram Desktop](https://github.com/telegramdesktop/tdesktop)).
Все функции AyuGram сохранены.

Что добавлено:

- имя и иконка Ember;
- полностью чёрная тема по умолчанию, оранжевый акцент;
- **Ember-подарок**: кнопка в профиле. Вы выбираете подарок из каталога Telegram (бесплатно, это не настоящий подарок),
  и его видят только пользователи Ember, открывшие ваш профиль.

Репозиторий хранит только изменения (`ember-overlay/`). Сборка клонирует AyuGram, накладывает их и компилирует,
см. [TUTORIAL.md](TUTORIAL.md).
